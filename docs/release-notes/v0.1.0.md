# Tumon 0.1.0 (first preview)

**Preview (pre-release).** Published 2026-11-28.

Tumon lets TeamTalk use your laptop camera or USB webcam, including cameras TeamTalk cannot set up by itself.
It adds a camera called **Tumon Camera** whose resolution list fills in without typing anything.

## Requirements

- Windows 11 (build 22000 or newer), 64-bit
- TeamTalk 5 (tested with 5.23)
- Administrator rights to install

## Install and use

1. Download `Tumon-Setup-0.1.0.exe` and run it. This preview is **not code-signed**, so Windows SmartScreen may warn:
   check the file's SHA-256 below, then choose *More info* and *Run anyway*.
2. Open **Tumon**, choose your camera, press **Start**.
3. In TeamTalk: *Preferences › Video Capture*: device **Tumon Camera**, resolution **640x480, FPS 30**, image format
   **YUY2**. Then turn on video transmission.

Your real camera turns on only while some program is using Tumon Camera. Without Tumon running, Tumon Camera shows
colour bars. To remove everything: *Settings › Apps › Installed apps › Tumon › Uninstall*.

The SHA-256 of the installer is on the GitHub release page.

## Known limitations

- Tested on one Windows 11 PC with its built-in camera; USB webcams are not yet tested.
- The TeamTalk **phone** app was seen showing red and blue swapped (a computer receiver showed correct colours), and
  some lag on the phone.
- TeamTalk remembers a camera by its position in the camera list. If cameras are added or removed, select Tumon Camera
  again.
- Not yet tried by a screen-reader user, although the controls report their names and roles correctly.
- Another program running as a signed-in user could send its own pictures through Tumon Camera (see
  [SECURITY.md](../../SECURITY.md)).
- No effects and no phone-as-camera yet.
