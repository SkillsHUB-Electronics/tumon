# Architecture decision records

A short record for each hard-to-reverse choice: what we decided, why, and what we gave up. Records are
never deleted; a changed decision gets a new record that supersedes the old one.

| # | Title | Status |
|---|---|---|
| [0001](0001-media-foundation-virtual-camera.md) | Use a Media Foundation virtual camera, not a DirectShow filter | Proposed (awaiting Milestone 0 test) |

## Template

Copy this into `NNNN-short-title.md`:

```markdown
# NNNN: Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem, what constraints, what evidence.

## Decision
What we will do.

## Consequences
What gets easier, what gets harder, what we give up, what to revisit.
```
